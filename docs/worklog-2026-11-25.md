## `code-brief-funnel-onboarding-dictation.md` — conversion release (A–E) — implemented, not shipped

Checked against the live source first. The BEFORE snippets, call sites and line numbers all
matched. `assembleDebug` + `testDebugUnitTest` passed (DictationTextTest: 8/8).

- **A. Funnel analytics:** added a new `util/Analytics.kt`, initialised in `TravelJournalApp.onCreate`.
  Events: `onboarding_complete`, `entry_created` (new entries only: entry_number, has_photos,
  has_video, used_dictation, is_premium), `paywall_view`, `paywall_dismissed`, `plan_selected`,
  `purchase_started/completed/cancelled/failed` (reason = exception simple name), `dictation_used`
  (ok/empty/cancelled). The `is_premium` user property is set from `billingManager.isPremium` in
  `JournalViewModel.init`. The route is now `Screen.Paywall` `paywall?source={source}` with `createRoute()`.
  Sources: entry_limit, drive_backup, file_backup, print_book, profile (both tiles),
  subscription_info, first_entry. `showFreeLimitNote` now shows only for `entry_limit`.
- **B. Onboarding:** every literal moved to strings. Slide 2 now describes the freemium model honestly.
- **C. Soft paywall:** shown once after a free user's first new entry. It needs
  `isPurchased == false` and `softPaywallShown == false` (DataStore `soft_paywall_shown`). The heading
  and subline appear when `source == "first_entry"`. The trial days come from the live `annualTrialDays`.
- **D. `ui/components/PremiumBadge.kt`:** shown on the Drive backup card, the Backup & restore card
  and the Print Book row (new `premiumBadge` param on `SettingsClickRow`).
- **E. Dictation:** title/story use `Sentences` capitalisation, location/trip use `Words`. On API 33+
  the recognizer is asked to format (`EXTRA_ENABLE_FORMATTING`) and `MAX_RESULTS = 1`. The story is now a
  `TextFieldValue`, so dictation inserts at the cursor via the new `util/DictationText.kt`. The title
  is capitalised on save.
- **Strings:** 14 new keys × 11 locales.

**Deviations:**
- **Adventure Reel badge skipped.** The reel button is hidden for free users (`JournalListScreen`
  `if (isPurchased)`), so a badge has nothing to sit on. Year in Travel isn't gated, so it gets no badge either.
- **3 extra onboarding keys** (`onboarding_next`, `onboarding_get_started`, `onboarding_skip`). The
  brief said "every literal" but left these out of its table. PurchaseScreen's hardcoded tagline
  now reuses `onboarding_tagline`.
- **DictationText handles CJK.** There's no joining space between CJK text, and a CJK chunk is
  closed with '。' instead of '.'. The brief's version would have produced "今日は晴れ。 海を見た.".
  The brief's `prev.endsWith("\n")` could never match (prev is trimEnd'd), so the check uses `before` instead.
- **`used_dictation` plumbing:** `NewEditEntryScreen.onSave` is now `(TravelEntry, Boolean)` and
  `saveEntry(entry, usedDictation = false)`.
- **Paywall events:** `paywall_dismissed` also fires on system back (BackHandler).
  `paywall_view` is guarded with rememberSaveable so a rotation doesn't log it twice.
- **`paywall_first_entry_sub`** takes `%1$d` (the brief said never to hardcode the 7).
- **F (12-locale Play release notes) deferred** to ship time (`ship-to-play`). No release notes
  were written yet.

**Before shipping:** this touches billing and the paywall, so verify on the S8+ first (soft paywall
on a fresh free account, the badges, cursor dictation) and check the events in Firebase DebugView.
